// LSP 手动触发模式设计

## 核心设计

### 1. 启动策略
- **默认不启动**：LSP 仅在用户明确触发时启动
- **语言粒度**：触发后该语言所有文件共享 LSP
- **资源透明**：状态栏实时显示内存占用
- **快速控制**：一键休眠/停止

### 2. 触发方式

#### 快捷键
- `Ctrl+L` 或 `Cmd+L`: 启动当前文件语言的 LSP
- `Ctrl+Shift+L`: 打开 LSP 管理面板
- `Ctrl+Alt+H`: 休眠当前 LSP
- `Ctrl+Alt+S`: 停止当前 LSP

#### 工具栏
- 状态栏 LSP 按钮
- 编辑器顶部 LSP 状态指示

### 3. 状态显示

#### 状态栏格式
```
[TypeScript] [● Modified] [🔌 LSP: 65 MB]    [⚡ Auto] [⚠ Large File]
```

#### LSP 状态图标
- `🔌` 未启动 - 灰色
- `⚡` 活跃 - 绿色
- `💤` 休眠 - 黄色
- `❌` 错误 - 红色

#### 点击行为
- 未启动 → 启动 LSP
- 活跃 → 打开管理菜单（休眠/停止/重启）
- 休眠 → 唤醒
- 错误 → 查看错误详情

### 4. 管理面板

```
┌─────────────────────────────────────┐
│ LSP Manager                       ✕ │
├─────────────────────────────────────┤
│ TypeScript    ⚡ Running    65 MB  │
│              [Hibernate] [Stop]     │
│                                      │
│ Rust          💤 Hibernated 35 MB  │
│              [Wake]    [Stop]       │
│                                      │
│ Python        🔌 Stopped       0 MB│
│              [Start]                │
├─────────────────────────────────────┤
│ Total: 100 MB                       │
│ [Hibernate All] [Stop All]          │
└─────────────────────────────────────┘
```

### 5. 内存监控

- 每 5 秒更新一次内存占用
- 显示在状态栏
- 超过阈值时警告

### 6. 自动休眠（可选）

- 默认 10 分钟无操作自动休眠
- 可在设置中调整
- 休眠前 5 秒提示

## 核心价值

1. **资源透明**：用户完全掌控资源消耗
2. **极简模式**：不触发时零开销
3. **按需使用**：需要时一键启动
4. **快速释放**：不需要时一键停止

## 优势对比

| 模式 | 内存 | 控制度 | 复杂度 |
|-----|------|-------|-------|
| 自动启动（VSCode） | 100-300 MB | 低 | 中 |
| **手动触发（我们的设计）** | **0-300 MB（可控）** | **高** | **低** |
| 不支持 LSP | 0 MB | - | - |
